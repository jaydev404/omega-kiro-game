# Startup Logistics

## Descripción

Startup Logistics es un juego arcade de gestión logística donde el jugador comienza siendo el único empleado de una pequeña empresa de envíos.

El objetivo consiste en completar la mayor cantidad posible de pedidos antes de finalizar la jornada para obtener dinero e invertirlo en mejoras permanentes.

## Plataforma objetivo

- Web (MVP)
- Desktop (Futuro)
- Mobile (Evaluación futura)

## Motor

Godot 4.6.2

## Género

Arcade
Gestión
Time Management

## Estilo visual

2D Isométrico (2.5D)

Todos los personajes, objetos y escenarios estarán construidos mediante sprites 2D.

No se utilizarán modelos 3D.

## Filosofía

- Gameplay primero.
- Desarrollo iterativo.
- Código modular.
- Sistemas desacoplados.
- MVP funcional antes de añadir contenido.
