# Workflow

Antes de escribir código:

1. Leer los Steering Files.
2. Leer el Spec correspondiente.
3. Implementar únicamente las tareas indicadas.
4. No modificar otros sistemas.
5. Si falta información, agregar un TODO antes de asumir comportamiento.
6. No crear funcionalidades no solicitadas.

Durante el MVP:

- Usar placeholders para todos los assets faltantes.
- Priorizar código funcional sobre efectos visuales.
- Mantener cada sistema desacoplado.
- Crear escenas reutilizables.
- Mantener compatibilidad con Godot 4.x.
