# Chaos Delivery

> *El almacén se volvió loco, los drones no paran y los paquetes no se entregan solos.*
> *Entrega los paquetes, esquiva las bombas, sobrevive tu turno. Tienes 10 minutos.*

**[Jugar demo en itch.io](https://jaydev404.itch.io/chaosdelivery)**

---

## Qué es

Startup Logistics es un arcade de supervivencia y entregas. Eres el único empleado de un almacén que perdió el control — los drones llueven objetos desde el techo sin parar, algunos son paquetes que debes entregar, otros son bombas que debes esquivar.

Cada entrega te da experiencia y monedas. Cada bomba que te golpea te acerca al game over. A los 10 minutos el sistema entra en modo caos total. El objetivo: aguantar el turno completo y entregar la mayor cantidad de paquetes posible.

---

## Cómo se juega

| Tecla | Acción |
|---|---|
| WASD / Flechas | Mover |
| E | Recoger / Soltar / Entregar |
| Esc | Pausar |

- Recoge los paquetes que dejan los drones
- Llévalos al punto de entrega del color correcto
- Esquiva las bombas — o recógelas y lánzalas lejos
- Sube de nivel eligiendo mejoras temporales
- Usa las monedas entre partidas para mejorar tu personaje de forma permanente

---

## Tipos de objetos

| Objeto | Qué hace |
|---|---|
| Caja / Pot / 3rd | Entregar en el punto correcto |
| Moneda Oro | +5 monedas al tocar |
| Moneda Plata | +1 moneda al tocar |
| Ruby | Elige una mejora temporal |
| Caja Sorpresa `?` | Revela: moneda, ruby o bomba |
| Bomba inmediata | Explota al caer |
| Bomba timer | Cuenta regresiva — puedes recogerla y lanzarla |

---

## Progresión

- **Durante la partida** — entrega paquetes para ganar XP y subir de nivel. Al subir elige entre mejoras temporales: más velocidad, más capacidad de carga o un escudo.
- **Entre partidas** — gasta las monedas en la tienda para mejorar de forma permanente: más corazones, más velocidad base, más capacidad, revivir una vez.
